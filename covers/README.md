# Cover images

Drop your 90s comic cover JPGs / PNGs in this folder. Filenames must match the `url` field for each entry in `../covers.json` exactly (case-sensitive).

Suggested prep for e-ink dithering:
- Resize the long side to ~800px
- Bump contrast a bit; e-ink loves crushed midtones
- JPG at ~85% is fine

The plugin will pick up any covers you add on its next poll (default 15 min).
